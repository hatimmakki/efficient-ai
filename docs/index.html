4-Layer Lossless Pipeline & Local CLI

100% LOCAL RUST BINARY · ZERO CLOUD TELEMETRY

Each station targets the next largest token-amplification driver in empirical order, never dropping diagnostics silently and never sending session data off your machine.

01

Static-Prefix Diet

−67.9% IDLE

Runs before turn 1 to audit and minify AGENTS.md, skill metadata, and MCP schemas. Built-in eai mcp stays at 248 idle tokens across 4 tools.

$ eai audit . --include-user --fix
02

Tree-Sitter AST Outline

−47.2% READS

Targets the 63.9% file-read share on files >200 lines: prints symbol signatures with [Lstart-Lend] spans, then fetches only the needed symbol.

$ eai outline file.py --symbol parse
03

Lossless Stream Squeeze

−92.6% LOGS

Compresses verbose test/build noise across 15+ runners while keeping 100% of errors, guards 3× stuck loops (H7), and spills raw bytes to .eai/logs/.

$ eai squeeze -- pytest -v
04

Cache-Aware Batch Proxy

−37.6% USD

Opt-in local proxy compacting old tool outputs (>6 turns) only at fixed K=12 turn boundaries, protecting 0.1× prompt-cache reads across providers.

$ eai proxy --provider anthropic
